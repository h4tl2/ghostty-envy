# ghostty-envy

[Ghostty](https://ghostty.org) port of [Envy](https://github.com/kkga/vim-envy), a light color scheme with comfortable contrast, by Gadzhi Kharkharov.

The colors come from the `vim-envy` color scheme, including its terminal palette.

## Install

Copy the `envy` file to the Ghostty themes folder:

```sh
mkdir -p ~/.config/ghostty/themes
curl -o ~/.config/ghostty/themes/envy https://raw.githubusercontent.com/h4tl2/ghostty-envy/main/envy
```

Then set the theme in your Ghostty config:

```
theme = envy
```

Reload the config or restart Ghostty.
